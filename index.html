LLM Gateway

A local, Anthropic-compatible gateway for Claude Code, with a desktop app to manage it. This page is the APT repository that serves it.

Install

curl -fsSL https://hasnat-shohag.github.io/llm-gateway/install.sh | sh

That script adds this repository and installs the package. If you would rather not pipe a script to a shell — a reasonable instinct — the steps below are exactly what it runs.

Install manually

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://hasnat-shohag.github.io/llm-gateway/llm-gateway-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/llm-gateway.gpg > /dev/null

sudo tee /etc/apt/sources.list.d/llm-gateway.sources > /dev/null <<'EOF'
Types: deb
URIs: https://hasnat-shohag.github.io/llm-gateway
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/llm-gateway.gpg
EOF

sudo apt update
sudo apt install llm-gateway

Update and remove

Updates arrive through apt upgrade like anything else. To remove the app and stop tracking the repository: 

sudo apt remove llm-gateway
sudo rm /etc/apt/sources.list.d/llm-gateway.sources /etc/apt/keyrings/llm-gateway.gpg

Configuration and usage history live in ~/.config/llm-gateway-desktop/ and are left alone by apt remove. Delete that directory for a clean reset.

Other architectures and distributions

Only amd64 is published here. Every release also ships an AppImage, which runs on any reasonably current Linux distribution — see the releases page.
